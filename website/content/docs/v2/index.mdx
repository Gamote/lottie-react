v2 wraps [lottie-web](https://github.com/airbnb/lottie-web) in a component and
a hook for rendering After Effects animations in React.

## Install

```npm
npm i lottie-react@^2
```

`react` and `react-dom` are peer dependencies, version 16.8.0 or newer.

## Using the component

```tsx
import Lottie from "lottie-react";
import groovyWalkAnimation from "./groovyWalk.json";

const App = () => <Lottie animationData={groovyWalkAnimation} loop={true} />;

export default App;
```

## Using the hook

```tsx
import { useLottie } from "lottie-react";
import groovyWalkAnimation from "./groovyWalk.json";

const App = () => {
  const options = {
    animationData: groovyWalkAnimation,
    loop: true,
  };

  const { View } = useLottie(options);

  return View;
};

export default App;
```
